# sketchfab-toolkit

Консольная программа для Windows: качает 3D-модели со Sketchfab и сохраняет их в glTF или OBJ.

Качаются только те модели, которые автор разрешил скачивать. Если автор запретил — программа так и скажет и ничего обходить не станет.

## Скачать

Последняя версия — в разделе [Releases](../../releases/latest). Там два файла:

| Файл | Кому |
| --- | --- |
| `sketchfab-toolkit-setup-1.0.0.exe` | обычный вариант: ставится в систему и работает из любого терминала |
| `sketchfab-toolkit.exe` | портативный: кладёте в любую папку и запускаете оттуда |

Рядом лежит `SHA256SUMS.txt` — контрольные суммы, если хочется проверить файлы.

## Установить

Запустите `sketchfab-toolkit-setup-1.0.0.exe`. Права администратора не нужны и спрашивать ничего не будет — просто поставит программу и покажет, что сделал:

```
  [1/4] Файлы скопированы в ...\AppData\Local\Programs\sketchfab-toolkit
  [2/4] Папка добавлена в PATH пользователя
  [3/4] Ярлык в меню «Пуск»
  [4/4] Программа появилась в «Приложениях и возможностях»
```

После установки откройте **новое** окно терминала (Win+R → `cmd` → Enter): в уже открытых окнах команда не появится. Проверка:

```
sketchfab-toolkit --version
```

Удалить можно из «Приложений и возможностей» или через `uninstall.cmd` в папке установки.

Портативный `sketchfab-toolkit.exe` ничего не устанавливает: положите его в удобную папку и запускайте оттуда.

## Токен

Программа обращается к Sketchfab от вашего имени, поэтому API нужен токен.

1. Откройте https://sketchfab.com/settings/password и скопируйте значение из раздела «API token».
2. Создайте рядом с `sketchfab-toolkit.exe` файл `.env`:

```
SKETCHFAB_API_TOKEN=сюда_токен
```

Для установленной версии это `%LOCALAPPDATA%\Programs\sketchfab-toolkit\.env`.

Проверить, что токен подошёл:

```
sketchfab-toolkit whoami
```

## Как пользоваться

Ссылку на модель просто скопируйте из адресной строки браузера.

Посмотреть, что за модель и разрешил ли автор скачивание:

```
sketchfab-toolkit info https://sketchfab.com/3d-models/...
```

Скачать (по умолчанию glTF):

```
sketchfab-toolkit download https://sketchfab.com/3d-models/...
```

Вместе с USDZ или в свою папку:

```
sketchfab-toolkit download https://sketchfab.com/3d-models/... --format both
sketchfab-toolkit download https://sketchfab.com/3d-models/... --out D:\models
```

Файлы складываются в папку `downloads` рядом с текущей папкой терминала: внутри `scene.gltf`, `scene.bin` и папка `textures`.

Отдельно есть конвертер. Если на диске лежит файл `file.osgjs` (формат вьюера OSG.js) вместе с `*.bin`, его можно превратить в glTF или OBJ без интернета:

```
sketchfab-toolkit convert "C:\models\scene\file.osgjs" --format obj
```

Все команды и ключи:

```
sketchfab-toolkit --help
```

## Если что-то не работает

**Windows пишет «Защитил ваш компьютер».** Сборки не подписаны сертификатом, это нормально: «Подробнее» → «Выполнить в любом случае».

**«sketchfab-toolkit не является внутренней или внешней командой».** Терминал был открыт до установки — закройте его и откройте заново.

**«Токен не принят (401)».** Токен скопирован не целиком, либо в `.env` попали кавычки или пробелы.

**«Автор не разрешил скачивание».** У модели отключена загрузка: программа это не обходит. Можно написать автору и попросить включить скачивание.

## Собрать самому

Из исходников, если нужен Python, а не exe:

```
pip install -r requirements.txt
python cli.py --help
```

Собрать exe и установщик:

```
powershell -ExecutionPolicy Bypass -File build.ps1
```

Что менялось от версии к версии — в [CHANGELOG.md](CHANGELOG.md).
